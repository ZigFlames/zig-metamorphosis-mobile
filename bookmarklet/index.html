Zig Morph on any website

Set this up once. Then you can morph videos on other websites.

Set up (one time)

  1. Copy the code.

  2. Save this page as a bookmark.
    Tap the Share button (square with an arrow ⬆, sometimes inside the ••• button). Tap Add Bookmark. Name it Zig Morph. Tap Save.
  3. Put the code in the bookmark.
    Open Bookmarks (the open book 📖). Tap Edit. Tap Zig Morph. Tap the web address under the name, clear it with ⓧ, then tap it again and choose Paste. Tap Done.

Use it

  1. Open a website with a video and start the video.
  2. Tap the address bar and type Zig Morph.
  3. Tap the Zig Morph bookmark in the list.

A small round button appears on the right. Tap it to choose an effect. To switch off, tap Off ✕, or tap the bookmark again.

Try it here

Play this video, then use your Zig Morph bookmark on this page.

⚠️ Nothing flashes faster than once a second, but the effects swirl. Brain Morph is the strongest. Stop if you feel dizzy.

A site says "blocked"?

Some websites block add-ons. Make a second bookmark the same way, named Zig Morph Max, using this code instead. It carries the whole effect inside the bookmark.

Some big sites (for example YouTube, Netflix, Instagram) block every bookmark in Safari. Nothing can run there. Protected videos (Netflix, Disney+ and similar) only get a light colour effect, but Brain Morph still works.
